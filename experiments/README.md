# experiments

Work that is not ready to be part of the library or a demo, but that is
not given up either.  Each directory has a README saying what it is,
what state it is in, and how to pick it up again.  Nothing here is built
by the Makefile and nothing in `src/`, `common/` or `skeleton/` depends
on it; a demo may still read an experiment's output (xtcdemo's `plfile`,
`town` and `file` scenes read `procgen/`'s).

* `procgen/` -- the procedural asset kit and the Greek town: prim list
  files (`.xpl`) generated by Python, an agent-artist workflow, a scene
  format.  The predecessor of the chunk pipeline.
